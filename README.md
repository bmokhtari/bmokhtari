# Hi, I'm Bilar Mokhtari

Software Engineering student at McGill University. I build full-stack web platforms, and occasionally the robots that need them.

## About

I'm a U4 Software Engineering (Co-Op) student at McGill with a minor in Aerospace Engineering. Most of my time goes into **RentAdvisor**, a platform that helps students avoid rental scams, where I work as Lead Developer. I own the deployment pipeline, build core product features, and lead a team of interns shipping to the same codebase.

Outside of coursework I stay involved in student communities. I spent three years as **VP Internal of GameDev McGill**, connecting students with people working in the game industry, and I was on the Mars Rover team at **McGill Robotics**. Those roles taught me more about running a project than any class did.

My interests sit at the intersection of **web platforms, cloud infrastructure, and embedded systems**. I like problems where the software has to survive contact with something real, whether that's users or hardware.

## Selected projects

| Project | What it is | Built with |
|---|---|---|
| **RentAdvisor** | Rental scam-prevention platform for students. Scam detection, listing verification, dual-backend deploys. | Nuxt 4, Vue 3, Firebase, Cloud Run |
| **McGill Seat Finder** | Real-time course seat availability, pulled from Banner/Horizon through a CORS proxy. | React, Cloudflare Workers |
| **ScamLens** | Browser extension that flags scam patterns on Marketplace, Kijiji, and Craigslist. | Manifest V3, weighted rules engine |
| **R1-D4** | Autonomous hospital assistant robot. Voice commands, pathfinding, subsystem comms. | Whisper, Dijkstra, TCP, ESP32 |
